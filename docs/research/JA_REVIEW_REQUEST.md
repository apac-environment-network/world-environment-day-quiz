## レビューポイント

### 優先度高

1. **不自然な日本語表現** — 「AIが書いたっぽい」「翻訳くさい」と感じる箇所はありますか？ 特にコロケーション（単語の組み合わせの自然さ）と助詞の使い方。
2. **トーンが不適切** — 大手金融機関の社内イベントとして不適切な表現はありますか？（特定の役職・部署を揶揄する表現は既に除去済みですが、他に引っかかる箇所があれば）
3. **笑いのツボ** — 間違い選択肢（ボケ）は「あるある」感がありますか？ 的外れだったり、笑えないほどズレていたりしませんか？

### 優先度中

4. **です・ます調の一貫性** — 文体が統一されているか（です・ます体とである体が混ざっていないか）
5. **長すぎる文章** — スマートフォンでの表示を想定しています。選択肢が長すぎて読みづらい箇所はありますか？
6. **事実誤認** — 解説部分に間違いがあればご指摘ください（ただし事実確認は英語のソースレポートで検証済みです）

### 具体的なやり方

各質問の下にコメントを直接書き込んでいただくか、修正案を赤字で入れていただければと思います。軽微な表現の修正も大歓迎です。

### Q1 — 世界環境デーの起源

**問題：** 世界環境デー（6月5日）は、1972年にある国が国連に提案したことで誕生しました。その国はどこ？

| | 選択肢 |
|---|---|
| A | 日本 |
| B | スウェーデン —— 「ストックホルムで会議を開いたのはウチだし、ついでに提案者もウチということに」 |
| C | ブラジル —— 「アマゾンがあるから環境の話といえばウチでしょ」と本気で思っていた |
| D | 実は複数国の共同提案で、どの国が最初に言い出したか、今でも国連の議事録をめぐって議論が続いている |

> **正解：A) 日本**
>
> 日本とセネガルが共同提案し、スウェーデンが主催し、国連が採択。以来、毎年6月5日は150カ国以上が参加する国連の環境啓発キャンペーンに。ちなみにこの提案、当時の日本の産業公害（水俣病やイタイイタイ病）への国際的批判を受けての「環境外交」でもあったそうです。ESGの源流には、いつも誰かの危機対応があるんですね。

### Q2 — クールビズ

**問題：** 日本の「クールビズ」キャンペーンで推奨されたオフィスのエアコン設定温度は？

| | 選択肢 |
|---|---|
| A | 25°C —— 28°Cは暑すぎると不評で、こっそり下げたオフィスが多数 |
| B | リモコンが行方不明で、結局誰も設定温度を変えられなかった |
| C | 28°C |
| D | 窓際と中央席で体感が違うため、室温28°Cの定義自体が曖昧 |

> **正解：C) 28°C**
>
> 2005年開始。スーツ禁止、半袖推奨。結果、年間約114万トンのCO₂削減に。今では「クールビズ」という言葉もすっかり定着し、夏のオフィス風景は一変しました。もっとも、「冷房28°C」を巡る社内の微妙な空気感だけは、20年経った今も変わっていないようですが。

### Q3 — もったいない

**問題：** 日本の「もったいない」の精神が3R（Reduce, Reuse, Recycle）に追加した4つ目の「R」とは？

| | 選択肢 |
|---|---|
| A | Relax（リラックス） —— もったいない精神で節約した分、たまにはご褒美を |
| B | Respect（敬意） |
| C | Report（レポート） —— 環境省が毎年「もったいない白書」を発行している |
| D | Really?（リアリー？） —— 観光客が「捨てるのもったいない。Really?」と言った |

> **正解：B) Respect（敬意）**
>
> ノーベル平和賞受賞者のワンガリ・マータイさんが世界的に広めた言葉です。ケニアの環境活動家だったマータイさんは、日本の「もったいない」という言葉に深く感銘を受け、4つ目のRとしてRespect（敬意）を提唱しました。日本の言葉と精神が、世界の環境運動に影響を与えた、誇らしいエピソードですね。

### Q4 — プラスチック・リサイクルの実態

**問題：** 日本のプラスチック「リサイクル率」は約85%と報告されていますが、国際基準での *実際の材料リサイクル率* は約何%？

| | 選択肢 |
|---|---|
| A | 約50% —— 環境省と経産省で計算方法が違い、数字が一致しない |
| B | 約62% —— 回収ボックスに入れた時点でリサイクル完了とみなす |
| C | 約85% —— 燃やして電気を作ることもリサイクルに含めているため |
| D | 約24% |

> **正解：D) 約24%**
>
> 85%には「サーマルリサイクル」（＝燃やして発電）が含まれています。EUではこれを「エネルギー回収」と呼び、リサイクルとは認めていません。ESGデータの世界へようこそ：すべての数字には脚注があり、その脚注にも脚注があります。

### Q5 — トランジション・ファイナンス

**問題：** 2024年現在、世界の「トランジションボンド（気候移行債）」発行市場において、日本は約何％のシェアを占めているでしょうか？

| | 選択肢 |
|---|---|
| A | 約70% |
| B | 約25% —— ただし、大半は国内の個人投資家向け市場に限られている |
| C | 約5% —— 日本企業は脱炭素化の資金調達において、債券よりも株式発行を好む傾向があるため |
| D | 0% —— 国連の気候タクソノミー（分類基準）への登録期限に間に合わなかったため |

> **正解：A) 約70%**
>
> 日本のGX（グリーントランスフォーメーション）政策がこの分野を牽引し、鉄鋼や海運など脱炭素化が難しい産業の移行を支援しています。日本は単なる投資撤退ではなく、実体経済の移行を支えるトランジション・ファイナンスの枠組み作りで世界をリードしています。

### Q6 — GX投資規模

**問題：** 日本の「GX（グリーントランスフォーメーション）」戦略が試算する、今後10年間に必要な官民投資総額は？

| | 選択肢 |
|---|---|
| A | 100兆円 —— 官民折半の原則で、政府50兆円＋企業50兆円 |
| B | 50兆円 —— その後、対象分野が増えるごとに金額が膨らんでいった |
| C | 150兆円（約1兆米ドル） |
| D | 200兆円 —— 物価上昇を見越して割り引くかで試算が大きく変わる |

> **正解：C) 150兆円（約1兆米ドル）**
>
> 年間GDPの約3%を、水素・洋上風力・次世代原子力など14〜16分野に投じる計画です。20兆円のGX経済移行債（世界初のソブリン気候移行債）で資金調達し、将来の炭素課金で返済するという循環型の資金メカニズム。壮大な構想であることは間違いありません。あとは実行あるのみ、ですね。

### Q7 — ESGファンド規制

**問題：** 金融庁の規則では、ネガティブスクリーニング（「タバコには投資しません」など）だけをESG戦略とするファンドを「ESGファンド」と名乗れますか？

| | 選択肢 |
|---|---|
| A | はい —— ファンド名に「サステナブル」「グリーン」等を含めればOK |
| B | いいえ —— ESGが主要な投資判断要素であり、具体的な目標開示が必要 |
| C | はい —— ただし「ESGを考慮しています」の一文を目論見書に入れる必要あり |
| D | いいえ —— ただし「ESGに配慮した運用」という表現なら別カテゴリーで可 |

> **正解：B) いいえ**
>
> 金融庁は2022〜2023年にかけて、グリーンウォッシング対策としてESGファンドの名称規制を強化しました。単に「タバコと武器を除外しています」だけでは不十分。明確なESG評価基準、参照ベンチマーク、継続的な情報開示が求められます。日本はこの分野で世界最先端の規制を導入した国の一つです。

### Q8 — ソブリン気候移行債

**問題：** 日本は2024年2月、世界初のソブリン気候移行債を発行しました。20兆円の債務はどう返済されますか？

| | 選択肢 |
|---|---|
| A | 新たな移行債を発行して既存の移行債を返済する「循環モデル」 |
| B | 「経済成長が返済をカバーする」—— GDP押し上げ効果が上回る前提 |
| C | 2050年のネットゼロと満期が一致し、「未来への投資」として資産計上 |
| D | 将来のGX-ETS炭素オークション収入と2028年導入の化石燃料課徴金 |

> **正解：D) 将来のGX-ETS炭素オークション収入と2028年導入の化石燃料課徴金**
>
> 炭素排出者に課金し、その収入で脱炭素投資のための国債を償還する——理論上は見事なクローズドループです。実際に機能するかは、炭素価格が計画通り上昇するか、排出者がきちんと支払うか、そしてこの仕組みが政治的に長続きするかにかかっています。世界初の試み。日本がどこまで成功させるか、世界中のESG関係者が注目しています。
